# 晨辉光影 (ChenHui Shaders)

一款为 **Minecraft 1.20+** 打造的高性能光影包，兼容 **Iris / Oculus**（Fabric）与 OptiFine。

## 特性

| 特性 | 说明 |
|---|---|
| ☁️ 体积云 | 程序化立体云层（y 205–222），风场漂移、太阳散射、真实云影投射 |
| 💧 水面反射 | 屏幕空间反射（SSR）+ 未命中回退天空/云反射，菲涅尔混合，波浪法线 |
| 🔥 动态光源 | 火把/灯笼/岩浆的屏幕空间光晕 + 火焰闪烁（LabPBR 自发光参与泛光） |
| 🧱 PBR 材质 | LabPBR 标准：光滑度/金属度/自发光 + 法线贴图（TBN 细节法线） |
| 🌞 圆形日月 | 太阳带米粒组织/黑子细节、环形山月亮，日月均有泛光光晕 |
| ✨ 丁达尔效应 | 光晕图沿太阳方向径向模糊 + 深度遮挡，真实光柱 |
| 🕳️ 末地黑洞 | 史瓦西黑洞：视界+光子环+倾斜吸积盘（多普勒增亮/湍流）+ 引力透镜星弧 |
| 🌧️ 惊艳雨景 | 雨丝滚动、镜头雨滴、湿润反光（wetness 驱动）、水面波纹增强、体积雾增强 |
| 🎛️ 中文参数 | 17 项参数全部中文显示 + 三档中文预设（性能/均衡/极致） |
| ⚡ 高效优化 | 半分辨率后处理链（scale 0.5）、采样数随画质档缩放、提前退出、无 TAA |

## 安装

1. 将 `晨辉光影` 文件夹（或 `晨辉光影.zip`）放入 `.minecraft/shaderpacks`
2. 需要 Fabric + **Iris**（或 **Oculus**）模组，1.20.x 及以上
3. 视频设置 → 光影 → 选择「晨辉光影」

## 目录结构

```
晨辉光影/
├── shaders/
│   ├── shaders.properties      # 分辨率缩放、三档预设
│   ├── lang/zh_CN.lang         # 全部参数中文名与说明
│   ├── lib/                    # 公共库（common/noise/sky/water/color）
│   ├── gbuffers_*.vsh|fsh      # 12 个正向渲染通道（PBR/动态光源标记）
│   ├── composite*.vsh|fsh      # 3 段后处理链（雾/云影 → 天空/云/光柱 → SSR/雨/色调映射）
│   ├── final.vsh|fsh           # 色彩分级/暗角/抖动
│   └── shadow.vsh|fsh          # 阴影图
└── 说明.txt                    # 中文安装与排障手册
```

## 技术要点

- 格式：OptiFine 兼容 legacy GLSL（`#version 120`），Iris/Oculus 完全兼容
- 缓冲：colortex0(gcolor)/1(gdepth)/2(gnormal)/4(gaux1 材质数据)/5(光晕)/6(场景)/7(合成场景)
- 选项：`#define` 编译期常量（各文件定义一致），预设用 `profile.` 批量切换
- 维度：无 `dimension` uniform，用固定雾色特征判定主世界/下界/末地
- 动态光源：gbuffers 标记发光体（方块光/自发光/已知光源方块 ID）→ gaux1.g →
  composite 汇入光晕图 → composite1 径向光柱 → composite2 邻域扩散

## 已知限制

- 动态光源为屏幕空间光晕式（非全局光照），光线不会真实投影到几何体上
- PBR 需搭配提供 `_n`/`_s` 贴图的材质包（PATRIX/Stratum/LAZY BD 等）
- 末地判定基于雾色特征，极端改雾色的模组可能导致黑洞不显示
- 若阴影反向（极少数显卡），将 `shadowSample` 中的比较符号反相即可
